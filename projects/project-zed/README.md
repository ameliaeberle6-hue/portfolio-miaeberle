# Project Zed — Before I Walk

A senior-year planner and graduation countdown app built to help students organize bucket-list goals and job-hunt tasks before graduation.

Live site: https://ameliaeberle6-hue.github.io/projectZED/

## Features

- Graduation countdown timer with saved date
- Senior bucket list with categories and local persistence
- Job application tracker with search, filters, and status tracking
